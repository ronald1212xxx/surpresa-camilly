# Surpresa para Camilly

Página romântica com um álbum interativo de dez fotos.

## Abrir

Depois que o GitHub Pages concluir a publicação:

https://ronald1212xxx.github.io/surpresa-camilly/

## Instalar no celular

- **Android:** abra o endereço no Chrome e escolha **Instalar app** ou **Adicionar à tela inicial**.
- **iPhone:** abra o endereço no Safari, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.

O álbum e as fotos ficam disponíveis offline depois da primeira visita. A música
abre nos serviços de streaming e precisa ser iniciada com um toque.
